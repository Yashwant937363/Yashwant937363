## 🚀 Featured Projects

### 👔 Wardly — AI-Powered Digital Wardrobe
An AI wardrobe assistant designed to recommend outfits using items from a user's own wardrobe.

- Organizes uploaded clothing items and their metadata.
- Combines semantic search and AI-powered recommendations to find relevant wardrobe items.
- Built with **Python, FastAPI, MongoDB, FashionCLIP, and LLM APIs**.

### 🌍 WorldGraph — Connecting the Dots in World Events
A knowledge-graph project that explores relationships between news events and helps investigate how events connect, what contributed to them, and what they may affect.

- Uses a graph to represent events, articles, and relationships.
- Explores event investigation and multi-hop connections.
- Built around **FalkorDB** and AI-assisted investigation.

### 🎧 QueueCast — Real-Time Collaborative Music
A collaborative music platform focused on real-time interactions and shared listening experiences.

- Explores real-time communication and synchronized user experiences.
- Built with **Go, React, PostgreSQL, Redis, and WebSockets**.
